# Patience

**Range:** 0–10 | **Default:** 5

Patience measures how much forbearance a character has left before they act
impulsively, escalate a confrontation, or abandon a careful plan. It is a
resource, not a trait: it depletes under pressure and recovers with rest or
small wins.

## Interpreting the scale

| Range | Tone          | What it implies                                                  |
|-------|---------------|------------------------------------------------------------------|
| 0–2   | At the limit  | The character is on the edge. A single provocation will cause    |
|       |               | them to break composure, lash out, or abandon the current plan. |
| 3–5   | Holding on    | The character is managing, but tension is visible. They can      |
|       |               | still deliberate, though they are slower to give ground.         |
| 6–8   | Composed      | The character is measured and in control. They can absorb        |
|       |               | setbacks and wait for a better moment without visible strain.    |
| 9–10  | Serene        | Exceptional composure — the character can wait almost            |
|       |               | indefinitely and is unlikely to be rattled by provocation.       |

## Agent guidance

Patience decreases when a character is pressured, stonewalled, humiliated,
or forced to wait while stakes rise. It increases when tension is released,
a goal is achieved, or the character gets space to breathe. Impulsive
actions (confronting someone prematurely, abandoning a stakeout) are
appropriate when Patience is at 0–2 and pressure continues. Never recover
more than 2 points of Patience in a single scene unless the character
explicitly withdraws to rest.
