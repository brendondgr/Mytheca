# Health

**Range:** 0–100 | **Default:** 100

Health measures a character's physical condition and capacity to act. It
reflects accumulated injury, exhaustion, and bodily wear — not courage or
resolve, which are tracked separately.

## Value bands

| Range  | Label                     | What it means                                                 |
|--------|---------------------------|---------------------------------------------------------------|
| 0–20   | Nearly dead               | The character is at death's door. Every exertion risks        |
|        |                           | collapse; they need immediate medical attention or rest.      |
| 21–40  | Badly hurt — needs to heal | Serious wounds impair movement and concentration. They can   |
|        |                           | act but pay a price; healing should be the first priority.   |
| 41–80  | Wounded but holding       | The character is hurt but functional — still capable in a     |
|        |                           | fight or a chase, though fatigue accumulates faster.          |
| 81–100 | Very healthy              | The character is in full physical form: no significant        |
|        |                           | injuries, stamina intact.                                     |

## Agent guidance

When proposing or adjusting Health, match the band to the character's
narrative situation. A character who just survived a brawl or a chase should
drop into 41–80 or lower. A character who has rested and received care should
recover toward 81–100. Never award Health above the current band's ceiling
without a plausible recovery event. At 0 the character is incapacitated.
