# Suspicion

**Range:** 0–10 | **Default:** 0

Suspicion measures how closely the authorities, factions, or relevant
third parties are watching a character. Low suspicion means freedom of
movement; high suspicion means scrutiny, interference, and danger.

## Value bands

| Range | Label     | What it means                                                          |
|-------|-----------|------------------------------------------------------------------------|
| 0–3   | Unnoticed | The character moves freely. No one is actively tracking their          |
|       |           | activities; they can operate without special precaution.               |
| 4–7   | Watched   | Someone has taken an interest. The character is not yet in             |
|       |           | immediate danger, but careless moves will sharpen the scrutiny.        |
| 8–10  | Hunted    | Active pursuit. Guards are on alert, informants are reporting, and     |
|       |           | the character risks arrest or worse if they surface in public.         |

## Agent guidance

Suspicion rises when a character is seen doing something incriminating,
fails a stealth or deception check, or is identified by a hostile witness.
It falls when time passes without incident, when evidence is suppressed,
or when the character successfully bribes or deceives the watching faction.
At 8+ the character should treat any public appearance as a significant risk.
Never drop suspicion more than 2–3 points without a concrete narrative reason.
