## D-NNN — <the decision, stated as a sentence, not a topic>

**Date:** YYYY-MM-DD
**Context:** What forced the choice. The constraint or finding that made this a
decision rather than a default.
**Options:** Each one considered, with the case for it. A list of one is not a
decision — it is a rationalisation.
**Decision:** What was chosen.
**Consequences:** What this costs. Include what it makes *harder* — incomparability
with prior work, a metric that must now be reported twice, a result that can no
longer be claimed. Reviewers ask "why did you use X?"; this is where the honest
answer already lives.
