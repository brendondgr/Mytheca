## Motivation

Why was it created, and for which task? If it was created for a specific experiment,
name the EXP ID.

## Composition

What is an instance? How many are there? What are the splits and how were they drawn?
Is anything missing, and why?

## Collection

How was it gathered or generated? By whom, over what period, with what tooling? If
LLM-generated, name the model **and version**, the prompts, and the sampling
parameters — a dataset generated by a rotating model alias is not reproducible.

## Preprocessing

What cleaning, filtering, labelling or normalisation was applied? Is the raw form
retained?

## Contamination

**Could this data plausibly appear in a pipeline model's training corpus?** State the
reasoning, not just a yes/no. If it is derived from anything committed to a public
repository, say so. If it uses recognisable fictional characters or settings, say so
— that is the documented pathway by which role-play scores get inflated
(arXiv:2603.03915).

## Uses

What has it been used for? What should it **not** be used for? Name any known bias or
artifact that would mislead a downstream user.

## Distribution

Will it be released? Under what licence, where, and with what DOI? If it is held
private for contamination hygiene, say that and cite the decision.

## Maintenance

Who maintains it? How are errata handled? Is it versioned, and how will a consumer
know a new version exists?
